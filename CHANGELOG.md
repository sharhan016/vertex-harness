# Changelog

All notable changes to Vertex are recorded here.

## 0.1.0 — 2026-10-03

Initial zero-to-one implementation:

- immutable project, task, dependency, and acceptance-criterion model;
- versioned, atomically updated repository state with cooperative locking;
- CLI workflow for initialization, task planning, blocking, and resumption;
- executable verification checks with source-bound evidence receipts;
- durable attempts, interruption recovery, and revision-bound checkpoints;
- conservative Python declaration/import index and impact queries;
- bounded agent context and dual-era read-only MCP stdio server;
- loopback-only read API and responsive dashboard; and
- Python packaging, diagnostics, CI, and release guidance.
